# Cuarenta Ecuador — React/Vite

Web app sencilla del juego de cartas cuarenta ecuatoriano, modo 1 vs IA local.

## Instalación

```bash
npm install
npm run dev
```

Luego abre la URL local que muestre Vite.

## Incluye

- React + Vite.
- Baraja de 40 cartas.
- Reparto de 5 cartas por jugador.
- Captura por igual, suma y secuencia.
- Bonificaciones de caída, limpia, caída y limpia, ronda y cuatro iguales.
- IA básica para rival.
- Puntaje hasta 40.
